# RunWay — Job Portal

A full-stack **Job Portal** built with the MERN stack, connecting job seekers with recruiters through a simple and user-friendly platform.

## 🚀 Features

* 🔐 User authentication & role-based access
* 👤 Student/Job Seeker profile management
* 💼 Browse and search jobs
* 📄 Apply for jobs
* 🏢 Recruiter company management
* 📌 Post and manage job vacancies
* 👥 View job applicants
* ✅ Update application status

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS, Vite, Axios
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Authentication:** JWT, bcrypt

## ⚙️ Run Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file in the `backend` folder with your MongoDB connection string and required environment variables.
